# Question 15: Mini User Management Application

## Description
A simple user management system built with HTML, CSS and Vanilla JavaScript.

## Features
- Register new users
- Retrieve all users
- Retrieve a user by ID
- Update user information
- Delete users
- Search users by name
- Prevent duplicate email addresses
- Validate user information
- Save user data using localStorage

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the question-15 folder in VS Code.
3. Open index.html using Live Server.
4. Register and manage users.

## Storage
User information is saved in the browser's localStorage.
