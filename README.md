# Grading Assignments

A collection of 15 interactive web-development assignments built with HTML, CSS, and vanilla JavaScript. The root `index.html` is the assignment directory and links to every demo.

## View the website

The site is configured for GitHub Pages at:

<https://ambassadorsavior.github.io/grading/>

After publishing, open that page and choose an assignment. The demos are static websites; assignment data saved in browser storage stays in that browser.

## Publish with GitHub Pages

1. Push the repository contents, including `index.html` and `.github/workflows/pages.yml`, to the `main` branch.
2. In the GitHub repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.
3. Open the **Actions** tab and confirm **Deploy static site to GitHub Pages** completes successfully. It deploys on each push to `main`; you can also start it with **Run workflow**.
4. Visit the website link above after deployment completes.

## Run locally

Open `index.html` in a browser, or serve the repository root with a local static web server. The assignments do not require a build step.
